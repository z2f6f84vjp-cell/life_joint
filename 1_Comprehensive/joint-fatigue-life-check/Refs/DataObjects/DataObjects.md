# 数据对象定义

推导方向: 终态 DO-07 向前推出过程 DO-06 DO-05 DO-04 DO-08 再推出输入 DO-01 DO-02 DO-03。
编号按推导顺序连续 DO-01 至 DO-08 执行主键见 Identity.md。

## DO-01 摆臂参数集(输入)

| 要素 | 内容 |
|---|---|
| 业务概念 | 摆臂寿命计算的13项参数 含运动学 质量惯量 疲劳寿命三组 |
| 核心用途 | 驱动双S曲线规划与扭矩疲劳积分 |
| 边界 | 只含摆臂模型参数 不含齿轮数据 |
| 数据形态 | arm_params.json |
| 流程角色 | AA-01 解析预设与覆盖项后落盘 |
| 产出方 | 校核工程师 AA-01 |
| 消费方 | AA-02 |
| 够了的标准 | 转速 总角位移 臂长 寿命指数 额定扭矩 参考转速 参考寿命均大于0 惯量模式合法 |
| 好的标准 | 预设来源与被覆盖的项在报告中可见 |
| 推导关系 | 输入 |

## DO-02 齿轮数据集(输入)

| 要素 | 内容 |
|---|---|
| 业务概念 | 4条腿乘3个关节共12个CSV 记录各位置各扭矩级的圈数 |
| 核心用途 | 提供逐位置逐扭矩级的啮合圈数 供损伤计算 |
| 边界 | 文件名须匹配 腿_关节.csv 内容须含 #TITLES 与 #DATA 标记 |
| 数据形态 | 12个CSV文件 加 gear_files_report.md 与各文件sha256 |
| 流程角色 | 校核工程师提供 AA-01 校验 |
| 产出方 | 校核工程师 |
| 消费方 | AA-01 AA-03 |
| 够了的标准 | 12个文件全部匹配 每行数据列数不少于扭矩级数 |
| 好的标准 | 文件sha256在AA-01与AA-03之间保持不变 |
| 推导关系 | 输入 |

## DO-03 齿轮校核参数(输入)

| 要素 | 内容 |
|---|---|
| 业务概念 | 齿轮接触疲劳校核的7项参数 TR NR LH M TEETH SIDE TW |
| 核心用途 | 决定额定预算D_allow与时间折算系数K |
| 边界 | 只含7项数值参数 不含扭矩数据 |
| 数据形态 | gear_params.json 中的 params 字段 |
| 流程角色 | AA-01 校验后落盘 |
| 产出方 | 校核工程师 AA-01 |
| 消费方 | AA-03 |
| 够了的标准 | 7项均为大于0的有限数 |
| 好的标准 | 取自工程师确认过的额定值或默认值 且在报告中回显 |
| 推导关系 | 输入 |

## DO-04 摆臂寿命结果(过程)

| 要素 | 内容 |
|---|---|
| 业务概念 | 双S曲线运动规划下的摆臂测试寿命 等效扭矩 疲劳积分 |
| 核心用途 | 给出摆臂测试寿命小时数 峰值扭矩与循环次数 供对比与评审 |
| 边界 | 仅在输入参数描述的单一工况下成立 不外推到其他运动规划 |
| 数据形态 | arm_result.json arm_summary.md arm_figures.png |
| 流程角色 | AA-02 产出 AA-04 AA-05 消费 |
| 产出方 | AA-02 |
| 消费方 | AA-04 AA-05 |
| 够了的标准 | Life与Teq为正的有限数 T_total等于6倍Ts |
| 好的标准 | 数值与原桌面工具同参数下一致 图表齐全 |
| 推导关系 | 由 DO-01 摆臂参数集计算得到 |

## DO-05 齿轮校核结果(过程)

| 要素 | 内容 |
|---|---|
| 业务概念 | 12个关节逐位置的单边啮合损伤与额定预算对比结果 |
| 核心用途 | 给出每个关节PASS或FAIL 安全系数 支持寿命 以及80%损伤风险位置 |
| 边界 | 按位置独立判定 取各关节最严苛位置 不跨位置累加 |
| 数据形态 | gear_result.json gear_per_position.csv gear_per_position_summary.csv gear_damage_position.md |
| 流程角色 | AA-03 产出 AA-04 AA-05 消费 |
| 产出方 | AA-03 |
| 消费方 | AA-04 AA-05 |
| 够了的标准 | 覆盖12个关节 D_allow等于TR的M次方乘NR 每个关节判定与最严苛位置的U一致 |
| 好的标准 | 逐位置明细可复算 风险位置清单可直接指导排查 |
| 推导关系 | 由 DO-02 的12个CSV 与 DO-03 的7项参数计算得到 |

## DO-06 跨模块对比结果(过程)

| 要素 | 内容 |
|---|---|
| 业务概念 | 以统一寿命指数p比较摆臂基准损伤D1与各关节齿轮损伤D2 |
| 核心用途 | 判断各关节的损伤主要来自齿轮接触疲劳还是摆臂模型基准 |
| 边界 | D1是整体基准不区分关节 比值大于1不等于校核失败 |
| 数据形态 | compare_result.json compare_table.csv compare_conclusion.md |
| 流程角色 | AA-04 产出 AA-05 消费 |
| 产出方 | AA-04 |
| 消费方 | AA-05 |
| 够了的标准 | D1为正的有限数 每个关节一行 按比值降序 |
| 好的标准 | p与D1 D2中使用的完全一致 结论文字说明了比值的含义边界 |
| 推导关系 | 由 DO-04 的峰值扭矩与循环次数 加 DO-05 各关节最严苛位置推出 |

## DO-07 综合校核报告(终态)

| 要素 | 内容 |
|---|---|
| 业务概念 | 把摆臂寿命 齿轮校核 跨模块对比三类结果合成一份结论先行的评审报告 |
| 核心用途 | 供校核工程师评审 决定接受 调整参数或补充数据 |
| 边界 | 只汇总上游已落盘的数值 不重新计算 不给出超出数据支持的结论 |
| 数据形态 | Markdown 文件 综合校核报告.md 与 report_summary.json |
| 流程角色 | AA-05 产出 AA-07 评审时消费 |
| 产出方 | AA-05 |
| 消费方 | AA-07 校核工程师 |
| 够了的标准 | 含总体判定 风险项 各关节明细 建议 交付文件清单五个章节 |
| 好的标准 | 每个数字能追溯到上游 json 文件 FAIL 关节全部列出 结论先于细节 |
| 推导关系 | 由 DO-04 DO-05 DO-06 汇总得到 |

| 推导关系 | 由各阶段产物与确定性规则得到 |
