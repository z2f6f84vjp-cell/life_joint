# T-06 run_pa all / selftest

- 脚本: `runtime/run_pa.py all|selftest`
- 封装对象: 依次调用 T-01 至 T-05 / 合成数据自检
- 命令格式: `python runtime/run_pa.py all 接受以上全部参数 selftest 无参数`
- 参数: all 接受以上全部参数 selftest 无参数
- 超时约定: all 约5分钟内 selftest 约1分钟
- 退出码: 0成功 1自检失败 2阶段失败
- 输入输出: selftest 只写系统临时目录并在结束时删除
- credential_ref: 无(本工具不使用任何凭据 不联网)
